# 🚁 无人机攻防 · 低空安防指挥官

> 俄乌战场题材的塔防游戏，建造侦测与反制体系，守护你的基地。
> 单文件 HTML5 Canvas 游戏，无需服务器，浏览器即开即玩。
> 同时兼容桌面端和移动端（手机/平板）。

🎮 **在线试玩**：启用 GitHub Pages 后，访问你的 Pages URL 即可游玩。

---

## 📖 玩法简介

你扮演反无人机指挥官，要在 7 关中守卫基地不被来袭无人机攻陷。

### 🎯 核心机制：先侦测，后反制

| 设备类型 | 作用 |
|---------|------|
| **侦测塔**（雷达站 / 光电侦测 / 频谱侦测） | 让无人机"被看见" |
| **反制塔**（频谱压制 / GPS干扰 / 网捕 / 激光） | 把被侦测的无人机"击落" |
| **物理塔**（动能拦截） | 必杀最后一关自主 AI |

⚠ **未侦测的无人机几乎打不到。** 所以开局第一件事永远是放侦测塔。

### 🖱 操作

1. **右侧/底部点装备卡** → 选中类型
2. **地图空地点击放置** → 建造（需 ¥）
3. 红色箭头是无人机来袭路径 → 在路径中段布防效率最高
4. **▶ 开始波次** → 等敌人来 → 看你的侦测-反制链生效
5. 升级 / 卖出 / 切换攻击目标（索敌策略）

### 🧠 三类索敌策略

| 策略 | 用途 |
|------|------|
| **先出现** | 攻击路径上最早的（拖延战） |
| **残血** | 一击必杀抢击杀分 |
| **最近基地** | 默认/兜底，防止漏防 |

每关有专属战术引导弹窗，第一关告诉你推荐开局位置。

### ⭐ 评分与排行榜

每关通关结算分数（基于血量、击杀、速度 × 难度系数），
评 S/A/B/C/D 五级，存到本地排行榜，下次进来可在首页看到你的历史最佳。

## 🌐 移动端适配

- ✅ 触摸事件（无右键取消 → 点无效格取消建造）
- ✅ 响应式布局（窄屏自动变底部抽屉式）
- ✅ 禁用画布手势（touch-action:none）
- ✅ 全屏弹窗覆盖（含底部抽屉）
- ✅ 加大点击区域

在手机浏览器打开链接即可玩，无需安装 App。

---

## 🛠 技术

- 纯 HTML5 Canvas 程序化绘制（无外部图片资源）
- Web Audio API 实时合成音效
- localStorage 自动存档 / 排行榜
- 单文件 ~165 KB，零依赖，离线可用

## 🏃 本地运行

直接双击 `index.html` 用浏览器打开即可，或：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080/
```
